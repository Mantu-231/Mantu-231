`FastAPI` `PostgreSQL` `SQLAlchemy` `scikit-learn` `React`

### 💰 [Finance Analytics System](https://github.com/Mantu-231/Finance-Analytics-System)

`Python` `FastAPI` `SQLite` `Streamlit` `Pandas` `Pytest`
